## 验证命令

```bash
cd vite-frontend
npm run lint
npm run build
```

本地验证至少覆盖：

- 聚合 token 存在且线路数大于 1；
- 只有一条线路或没有聚合 token；
- 直连/中转筛选；
- 有配额/不限配额；
- 永久/有到期时间；
- 线路停用、账号禁用、账号到期、加载中、空状态；
- 复制成功/失败与二维码展开/收起；
- 2048×969、1366×768、768px 以下视口。

## 风险控制

- 先只改 `my-sub.tsx`；除非构建或布局验证证明必须抽组件/改全局样式，否则不扩大文件范围。
- 不改 API、后端和数据库；如果发现后端返回结构不满足当前页面，先停回规划阶段，不在本任务内修改契约。
- QA 发现视觉偏差时优先修复布局、溢出、对比度和操作可达性，再处理 P3 装饰性细节。
