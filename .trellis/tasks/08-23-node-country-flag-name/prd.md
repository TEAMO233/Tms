# 节点订阅显示名加国旗+国家码前缀

## Goal

订阅里展示给客户端的节点名改为「国旗 emoji + ISO 国家简写 + 协议名」格式,例如新加坡机器上的 VLESS 显示为 `🇸🇬 SG VLESS`。国家码不需要人工维护:面板根据节点的公网 IP 自动 GeoIP 探测并落库。

## Background

- 现状:一键搭建整机协议(`oneClickCreate`)不写备注,单线路订阅节点名只有协议名(`VLESS`/`Trojan`/…),聚合订阅为 `{机器名} {协议名}`。多台机器的节点在客户端里难以一眼区分归属地区。
- 代码位置:命名逻辑全部在后端 `InboundServiceImpl`(`buildClientLink` / `buildAggregateSubscription` / `protocolDisplayName`),订阅内容由后端生成,客户端零改动。

## Requirements

### R1 国家码自动探测(核心)

- `node` 表新增 `country` 字段(ISO 3166-1 alpha-2,如 `SG`、`JP`、`US`,可空)。
- 面板在节点创建(`createNode`)与节点更新(`updateNode`)时,若公网 IP(`serverIp`,空则退回 `ip`)非空且 `country` 为空或 IP 发生变化,则调用 GeoIP 接口探测国家码并落库。
- GeoIP 探测失败(超时、内网 IP、接口不可达)不报错、不阻塞节点创建/更新流程,仅记日志;`country` 留空。

### R2 订阅显示名(核心)

- 单线路订阅:节点名 = `国旗 国码 协议名`(如 `🇸🇬 SG VLESS`);备注非空时仍优先用备注(备注前同样加旗+国码前缀)。
- 「全部线路」聚合订阅:按用户已确认的格式,`{机器名} {协议名}` 改为 `{国旗} {国码} {协议名}`;中转线路的 `→落地名` 段保留。
- 国旗 emoji 由 alpha-2 码推导(regional indicator symbol),无需单独存储。
- `country` 为空(探测失败/老数据未探测)时,回退为现有命名行为(无前缀,聚合订阅继续用机器名),保证不出现 `null`/空段。

### R3 可见性与兜底修正(次要)

- 面板节点列表能看到探测到的国家(国旗+国码)。
- 节点编辑表单允许手动修正 `country`(自动探测可能误判,如 CDN/中转出口)。

## Constraints

- 已装面板通过 `SchemaMigration` 自动加列,新装走 `gost.sql`,两处都要覆盖(项目既有约定)。
- GeoIP 依赖外部接口,必须设短超时(≤3s),且不能因外部接口故障拖垮节点管理接口。
- 不改动客户端/订阅链接的协议参数,只改展示名(remark 字段)。

## Acceptance Criteria

- [ ] 新装与老面板升级后 `node` 表均有 `country` 列(幂等迁移)。
- [ ] 创建/更新节点填了公网 IP 后,`country` 自动填充为正确的 ISO alpha-2 码;GeoIP 接口不可达时流程正常完成、日志有记录。
- [ ] 节点 `country=SG` 时,单线路订阅与聚合订阅中该机协议节点名均为 `🇸🇬 SG VLESS` 格式;中转线路形如 `🇸🇬 SG →落地名 Trojan`。
- [ ] `country` 为空的节点,订阅名与改动前完全一致(聚合订阅仍显示机器名)。
- [ ] 节点列表页显示国旗+国码;编辑表单可手动修改并保存生效。
- [ ] 后端编译通过,现有测试(如有)不回归。

## Out of Scope

- 落地(Landing)机的国家探测:中转线路前缀取前置机国家,落地出口国家不在本期范围。
- 批量重探/定时刷新任务(本期只在创建/更新时探测)。
